# Mutable-loan boundary fragments

These `.open.lc` files are annotated fragments, not complete programs or decided
litmus. The owner-adopted rule and small decided cases are in `spec/contracts.md`
and `litmus/contracts/`. The worked native Vec source and support interface moved
to [the future workload crate](../../../studies/mutable-loans/README.md).

The snapshot of proposed expectations here is retained as experimental evidence.
It does not add new accepted syntax or make the fragments independently runnable.
