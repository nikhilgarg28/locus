# A small core. A longer horizon.

The project grows by making each new piece precise, testable, and usable from Rust. This roadmap preserves the projects and permanent **LOC** task numbers from Atlas. It records direction and current work, not release dates.

<!-- component: roadmap -->

## Reading the plan

Open a project to see its tasks, status, and acceptance notes. A task's LOC number is its public identity and remains stable when the task moves. Completed core work stays visible beside planned extensions so the history is inspectable.

The language manual describes implemented behavior. Design notes describe intended behavior. A roadmap task is not evidence that its feature exists: follow the associated manual rule, test, or implementation before relying on it.
