L0276: Named proposition needs separate body evidence

A named arm’s evidence belongs after the @ separator, outside the witness argument list. This keeps a tuple of witnesses distinct from the proof of the arm formula. Write Constructor(witnesses) @ evidence, with an expected claim when needed.

Example from `tests/corpus/reject/prop_missing_evidence.lc`; the full file is a regression test.

```rust
prop P { Yes => { prop!(true) } }
fn bad() -> @P {
    P::Yes(prove!(true))
}
```
