L0220: Expression does not have the expected type

The expression or block result disagrees with the type required at this position. This includes a block ending without a value. Follow the actual/expected types in the message; a proposition value is not evidence of that proposition and a logical value is not runtime data.

Example from `tests/corpus/reject/block_without_value.lc`; the full file is a regression test.

```rust
// A block that ends in a statement where a value is needed.
fn first(n: u8) -> u8 {
    let m = n;
}
```

Language, as built: [1.3:1](../../atlas.html#/doc/language/spec-1.3:1).
