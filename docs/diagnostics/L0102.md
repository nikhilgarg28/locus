L0102: Expected syntax token

The parser required a particular token, often a semicolon after a let binding, but found another token or the end of input. Follow the primary diagnostic for the required token; this error does not imply the surrounding expression has been type checked.

Example from `tests/corpus/reject/missing_semicolon.lc`; the full file is a regression test.

```rust
// A `let` without its `;`.
fn first(n: u8) -> u8 {
    let m = n
    m
}
```

Language, as built: [1.0:2](../../atlas.html#/doc/language/spec-1.0:2).
