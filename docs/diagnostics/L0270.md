L0270: Logical context violates its boundary

A logical definition or callable violates a required restriction, such as returning runtime data, using runtime control flow, or invoking an effectful operation. Logical computations are erased and must remain pure and total. Model physical inputs explicitly and keep logical results logical.

Example from `tests/corpus/reject/fn_type.lc`; the full file is a regression test.

```rust
// A parameter of `fn` type is a function of the logic, and a call applies
// it only in a proposition, not at runtime.
fn apply(f: fn(u8) -> u8, n: u8) -> u8 {
    f(n)
}
```
