L0108: Parser nesting or chain limit

A deeply nested expression or very long operator chain exceeds a bounded parser budget. Split it into named intermediate expressions or declarations. The limit prevents adversarial input from exhausting the compiler stack; it is not a logical inconsistency.

Example from `tests/corpus/reject/chain_limit.lc`; the full file is a regression test.

```locus
// One expression with more operators in a row than the parser's limit.
fn long() -> bool {
    true && true && true && true && true && true && true && true && true && true && true && true && true && true && true && true && true && true && true && true && true && true &&  …
}
```
