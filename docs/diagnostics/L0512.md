L0512: Rust interface extraction failed

Locus could not acquire or validate a native Rust interface. Imports require a Cargo host and a supported, matching rustc/rustdoc toolchain. The diagnostic includes the failing tool's explanation. Select the intended manifest, features and target; install a missing target component if needed. A schema-version error requires a compatible Locus adapter, not installing nightly.

An import has no `pub` or attributes. Use `pub use` after binding it. Native signature validation can also reject a rustdoc declaration exposed only under `cfg(doc)`.

Recursive host build-script extraction and existing rustc wrappers are currently unsupported. Generate before building a host that needs the generated source; do not suppress the diagnostic.
