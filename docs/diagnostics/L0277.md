L0277: Inductive proposition is not a function definition

Named proposition arms introduce evidence through constructors. They are opened by proof matching, not unfolded as if the proposition were a function body. Match the arm to obtain its body evidence; fold or unfold any actual logical function used inside that body separately.

Example from `tests/corpus/reject/prop_unfold.lc`; the full file is a regression test.

```locus
prop P { Yes => { prop!(true) } }
fn bad(h: @P) -> @(true) {
    unfold!(P, h)
}
```

Language, as built: [1.6:6](../../atlas.html#/doc/language/spec-1.6:6).
