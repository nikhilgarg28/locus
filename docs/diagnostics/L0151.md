L0151: Invalid left side of an evidence pattern

The left side of an @ pattern identifies a named proposition arm, not an arbitrary tuple pattern. Place witness bindings inside that arm pattern; the pattern after @ binds the evidence of its body. A whole-proof binding uses the documented parenthesized pattern.

Example from `tests/corpus/reject/evidence_pattern_left.lc`; the full file is a regression test.

```rust
fn bad(p: u8) -> u8 {
    let (a, b) @ evidence = p;
    p
}
```

Language, as built: [1.7:5](../../atlas.html#/doc/language/spec-1.7:5).
