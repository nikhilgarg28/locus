L0206: Proof hole used for ordinary data

An underscore hole requests evidence of an expected proposition. It does not ask the compiler to invent an arbitrary runtime or logical data value. Supply a concrete data expression; keep holes at proof-typed positions with a known goal.

Example from `tests/corpus/reject/hole_for_data.lc`; the full file is a regression test.

```rust
// `_` where a `u8` is needed: a hole is filled with evidence, never data.
fn first(n: u8) -> u8 {
    _
}
```

Language, as built: [1.7:1](../../atlas.html#/doc/language/spec-1.7:1).
