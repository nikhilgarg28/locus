L0401: Input or output operation failed

The driver could not read an input or write an output, including a source file, explicit library or proof store. Check the path and filesystem permissions. No theorem or program result is inferred from an I/O failure.

Driver/resource example; generated-input tests cover this case.

```text
locus check does-not-exist.lc --error-format json
```
