L0244: Built-in form has invalid arguments

The recognized form received the wrong argument count or an invalid argument shape. An assertion needs a condition, and a panic message uses the supported literal syntax. Follow the form-specific signature in the primary diagnostic.

Example from `tests/corpus/reject/form_arguments.lc`; the full file is a regression test.

```locus
// The arguments of the forms that panic: `assert!` takes a condition, and
// a message is a string literal.
fn empty() -> u8 {
    assert!();
    1
}

fn not_a_literal(n: u8) -> u8 {
    panic!(n)
}

fn not_a_literal_either(n: u8) -> u8 {
    assert!(n <= 3, n);
    n
}
```
