L0217: Loop control outside a loop

break and continue need an enclosing loop that they can target. A surrounding function or ordinary block is not a loop. Return a value from the function, or move the control statement inside the intended loop body.

Example from `tests/corpus/reject/break_outside_loop.lc`; the full file is a regression test.

```locus
// `break` and `continue` with no loop around them.
fn first(n: u8) -> u8 {
    break n
}

fn second(n: u8) -> u8 {
    continue
}
```
