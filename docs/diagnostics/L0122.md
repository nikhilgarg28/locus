L0122: Visibility in an unsupported position

pub belongs on supported declarations and fields, not every syntactic component. Enum variants share their enum visibility and function parameters are local names. Move or remove the visibility marker; public invariant-bearing fields also have separate soundness checks.

Example from `tests/corpus/reject/visibility_misplaced.lc`; the full file is a regression test.

```rust
// `pub` goes on items and on struct fields; nothing else can be made
// visible on its own.
pub impl Counter {
    pub fn get(n: u8) -> u8 { n }
}

enum Event {
    pub Wrong,
    Right,
}

fn first(pub n: u8) -> u8 { n }
```
