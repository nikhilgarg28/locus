L0286: Shared reference escapes or becomes stale

The returned or stored reference would outlive its source, or an overlapping write or move invalidated the permission it relies on. Lifetimes describe real source provenance, not a promise that makes local storage permanent. Return a reference tied to a valid input or return owned data.

Example from `tests/corpus/reject/shared_permissions.lc`; the full file is a regression test.
