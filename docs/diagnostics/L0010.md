L0010: Source size limit exceeded

The assembled compilation unit exceeds the documented source-byte limit. This is a resource limit, not a failed theorem. Reduce the entry and explicit library inputs or split independently checked units; the compiler does not silently truncate source text.

Driver/resource example; generated-input tests cover this case.

```text
# Generate source larger than the configured limit.
python3 -c 'print(" " * ((64 << 20) + 1))' > oversized.lc
locus check oversized.lc
```

Language, as built: [1.24:1](../../atlas.html#/doc/language/spec-1.24:1).
