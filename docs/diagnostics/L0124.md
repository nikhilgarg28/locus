L0124: Assignment used as a value

Assignment is a statement in Locus. It cannot initialize another binding, supply a function argument or serve as an if condition. Perform the assignment as a separate statement and then use the updated place or a Boolean comparison.

Example from `tests/corpus/reject/assignment_as_value.lc`; the full file is a regression test.

```locus
// Assignment is a statement in Locus, not an expression of type `()` as in
// Rust, so it has no value. Where Rust would let one stand, the message
// says to write it on its own line, or `==` if a comparison was meant.
fn f(x: u8, y: u8) -> u8 {
    let mut total = x;
    let z = total = y;
    if total = 3 { 1 } else { 2 };
    g(total = 5);
    total
}
```
