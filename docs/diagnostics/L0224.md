L0224: Constructor field syntax does not match its declaration

Tuple variants use parentheses; named variants use braces and the declared labels. The two spellings are not interchangeable even if their payload types happen to match. Follow the constructor declaration’s field shape.

Example from `tests/corpus/reject/named_variant_fields.lc`; the full file is a regression test.

```rust
// tuple variant is not.
enum Shape {
    Line(u8),
    Box { width: u8, height: u8 },
}

fn as_tuple() -> Shape {
    Shape::Box(1, 2)
}
```

Language, as built: [1.3:2](../../atlas.html#/doc/language/spec-1.3:2).
