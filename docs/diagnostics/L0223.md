L0223: Unsupported logical comparison

The requested relation is not defined for these operand types. For example, logical equality of Booleans is meaningful but numeric ordering of them is not provided. Use a relation with a checked declaration for the intended type.

Example from `tests/corpus/reject/ordering_of_bools.lc`; the full file is a regression test.

```rust
// `<` in a proposition is defined on the integer types.
fn first(a: bool, b: bool) -> @(a < b) {
    _
}
```

Language, as built: [1.6:1](../../atlas.html#/doc/language/spec-1.6:1).
