L0261: Call cannot lend the required place

A reference parameter requires a source place with the appropriate borrowing permission. A temporary receiver may not provide a place that this method can lend. Bind the value first or use a by-value method with a compatible ownership contract.

Example from `tests/corpus/reject/method_call_shapes.lc`; the full file is a regression test.

```rust
// A method call lends or moves its receiver as the method's `self` says,
// under the rules of O3: `&mut self` needs a mutable place, a reference
// receiver needs a place at all, and an associated function has no
// receiver. A method is found by the receiver's type, and never as a free
// function.
#[derive(Clone, Copy, Debug)]
struct Counter {
    count: u8,
}

impl Counter {
    fn fresh() -> Counter {
        Counter { count: 0 }
    }

    fn get(&self) -> u8 {
        self.count
    }

    fn bump(&mut self) -> () {
        self.count = self.count.wrapping_add(1);
    }
}

fn immutable_receiver() -> u8 {
    let c = Counter::fresh();
    c.bump();
    c.count
}

fn temporary_receiver() -> u8 {
    Counter::fresh().get()
}

fn associated_as_method(c: Counter) -> Counter {
    c.fresh()
}

fn unknown_method(c: Counter) -> u8 {
    c.size()
}

fn method_as_free_function(c: Counter) -> u8 {
    get(c)
}
```
