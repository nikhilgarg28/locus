L0247: Tracked evidence has no mutable dependency

A mutable evidence binding is intended to track a claim about mutable state. This claim has no dependency that can change, so the tracking machinery is unnecessary. Use an ordinary immutable proof binding to express a historical fact.

Example from `tests/corpus/accept/unreachable_statement.lc`; the full file is a regression test.
