L0282: Model observation is missing or incompatible

A physical type has one canonical Model implementation with an associated Logical type. Define it with `impl Model for T { type Logic = M; ... }`. Use `model!(object.field)` to observe a physical field when its enclosing object has no model. The form accepts read paths, not executable calls. Models cannot overlap, and a logical cast cannot select another model or turn logical information into runtime data. Array lengths, vector layouts and borrowed slices retain their physical shape checks.

Example from `tests/corpus/reject/model_bridge_missing.lc`; the full file is a regression test.

```rust
#[derive(Logical)] struct Observation { value: Int }
fn observe(value: u8) -> Observation { value as Observation }
```
