L0513: Native Rust name was not found

The selected Rust interface does not contain this public name. Check the dependency's Cargo alias, spelling, visibility and enabled target/features. `crate` selects the owning package's Rust library. `locus import dependency --json` shows the actual extracted interface. Sysroot imports such as `std::vec::Vec` are not implemented yet.

An unavailable item is different from an absent item: retained async, unsafe or native type declarations instead report L0514 when used.

```text prose cargo-fixture-diagnostic
import dependency::misspelled;
```
