L0402: Proof store entry was not reusable

The saved directory lockfile contains invalid, stale or unsupported data. The store is only a cache: its entries must still be checked and may be replaced by fresh proof search. In locked mode a missing usable certificate remains an error; this warning does not authorize unchecked evidence.

Driver/resource example; generated-input tests cover this case.

```text
printf invalid > Locus.lock
locus check program.lc
```
