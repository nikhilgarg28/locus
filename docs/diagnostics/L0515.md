L0515: Trait declaration or implementation is invalid

A trait implementation must supply the required members, match their resolved signatures and belong to a package that owns the trait or concrete type. Proof input/output claims and logical mode are part of the signature. A missing member or mismatch labels the corresponding trait header. Duplicate implementations are rejected even when the trait was imported under different aliases.

A trait name cannot be used as a concrete type. Generic traits/methods, blanket implementations and supertraits are deferred; use a concrete implementation in the supported subset. This diagnostic does not grant an assumption or suppress body checking.

```rust reject L0515
trait Read { fn read(&self) -> u8; }
struct Counter {}
impl Read for Counter { fn read(&self) -> bool { true } }
```
