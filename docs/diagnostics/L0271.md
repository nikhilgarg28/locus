L0271: Obsolete ghost or snapshot syntax

The old Ghost and snapshot spellings have been replaced by the logical/physical type split and model observations. Use a logical model type and an explicit as cast. Erasure belongs to the type and checked logical computation, not a special binding wrapper.

Example from `tests/corpus/reject/ghost_contexts.lc`; the full file is a regression test.

```rust
// Effects cannot enter an explicit logical block, even if its result erases.
fn may_loop(n: u8) -> u8 { n }
#[terminates] #[no_panic] #[no_io]
fn promised(n: u8) -> u8 { n }
fn in_logic(n: u8) -> Int {
    logic { may_loop(n) as Int }
}
fn in_formula(n: u8) -> Prop {
    prop!(promised(n) == n)
}
// Classification belongs to the type, not a binding qualifier.
fn cannot_extract(n: u8) -> u8 {
    let observed: Int = n as Int;
    observed as u8
}
fn old_binding(n: u8) -> u8 {
    let old: Ghost<u8> = n;
    n
}
fn old_snapshot(n: u8) -> Int {
    snapshot!(n)
}
```
