L0275: Named proposition witnesses do not match

The arm’s tuple or named witness fields must match its declaration. Witnesses choose the proposition instance but do not by themselves prove the arm body. Supply the declared witnesses in their proper shape, followed by @ and body evidence.

Example from `tests/corpus/reject/prop_missing_witness.lc`; the full file is a regression test.

```locus
prop P { At(index: Int) => { prop!(true) } }
fn bad() -> @P {
    P::At @ prove!(true)
}
```
