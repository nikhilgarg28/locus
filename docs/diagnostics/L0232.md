L0232: Write to an immutable binding

Assignment or a mutable borrow requires a writable place. Ordinary let bindings and unmarked value parameters are immutable. Introduce a mut binding when mutation is intended; do not change proof snapshots into live mutable references.

Example from `tests/corpus/reject/assign_immutable.lc`; the full file is a regression test.

```locus
// Assignment needs `let mut`, in Rust's words. A parameter cannot be
// assigned either, until `mut` parameters mean something.
fn f(n: u8) -> u8 {
    let total = n;
    total = 1;
    n = 2;
    total
}
```
