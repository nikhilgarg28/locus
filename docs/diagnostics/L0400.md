L0400: Invalid command-line arguments

The command or one of its options has the wrong shape, an unknown value or a duplicate setting. Use locus --help and supply one --error-format value, text or json. This is a driver error before language checking.

Driver/resource example; generated-input tests cover this case.

```text
locus check program.lc --error-format yaml
```

Language, as built: [1.21:1](../../atlas.html#/doc/language/spec-1.21:1).
