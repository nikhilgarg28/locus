L0281: Invalid generic bound or instantiation

A generic declaration or concrete use lacks a required trait implementation, has incompatible associated types, uses a member outside its declared bounds, cannot infer its arguments, or exceeds a specialization limit. The diagnostic identifies the requirement and its source. Use an explicit bound or type argument; qualify ambiguous members with `<T as Trait>::member`.

`Logical` classification is supported alongside ordinary named trait bounds. Compiler-integrated bounds such as `Copy` and `Model` remain separate work. An unused generic body is not a universally checked proof.

Example from `tests/corpus/reject/generic_bound.lc`; the full file is a regression test.

```rust
struct Wrapper<T: Debug> { value: T }
```
