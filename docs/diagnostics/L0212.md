L0212: Pattern belongs to another type

The match arm names a constructor from an enum or proposition different from the value being matched. Constructors are nominally tied to their declaration. Use the receiver type’s variants and keep proof patterns separate from runtime data patterns.

Example from `tests/corpus/reject/arm_of_another_enum.lc`; the full file is a regression test.

```locus
// An arm for an enum other than the one matched.
enum Light {
    Red,
    Green,
}

enum Event {
    Wrong,
    Right,
}

fn go(light: Light) -> bool {
    match light {
        Light::Red => false,
        Event::Right => true,
    }
}
```
