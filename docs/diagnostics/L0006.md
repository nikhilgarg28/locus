L0006: Unterminated string literal

A double-quoted string must have a closing quote. Escape a quote inside a message with a backslash. This is a lexical failure, so type checking has not yet considered whether the surrounding form accepts a string.

Example from `tests/corpus/reject/unterminated_string.lc`; the full file is a regression test.

```locus
// A string literal that never closes takes the rest of the file with it.
fn greeting() -> u8 {
    "hello
}
```

Language, as built: [1.0:2](../../atlas.html#/doc/language/spec-1.0:2).
