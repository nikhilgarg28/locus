L0516: Trait member selection is ambiguous

More than one trait in scope supplies this member for the concrete type. Select the interface explicitly with `<Type as Trait>::method(&value, arguments)` or the corresponding qualified associated item. Renaming a trait import does not change its identity.

```rust reject L0516
trait Left { fn read(&self) -> u8; }
trait Right { fn read(&self) -> u8; }
struct Counter {}
impl Left for Counter { fn read(&self) -> u8 { 1 } }
impl Right for Counter { fn read(&self) -> u8 { 2 } }
fn example() -> u8 { let counter = Counter {}; counter.read() }
```
