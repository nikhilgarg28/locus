L0213: Non-exhaustive match

The match omits a possible constructor. Every reachable data or proof alternative must be handled unless the checker has evidence that makes it impossible. Add the missing arm or an appropriate wildcard; a guessed unreachable arm is not a proof.

Example from `tests/corpus/reject/missing_arm.lc`; the full file is a regression test.

```locus
enum Light {
    Red,
    Green,
}

fn go(light: Light) -> bool {
    match light {
        Light::Red => false,
    }
}
```
