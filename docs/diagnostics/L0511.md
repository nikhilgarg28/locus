L0511: Specification and implementation disagree

A loaded spec needs one complete implementation in its owning package. Resolved signatures must agree, including proof propositions and receiver modes. Generic implementations must cover the whole declared family. Unlisted implementation members belong in an ordinary backing-type impl.

```rust reject L0511
spec type Counter { fn read() -> u8; }
struct Representation {}
impl Counter for Representation { fn read() -> u16 { 0 } }
```

Supply the required signature and a checked body. A member mismatch points to both its implementation and its required header. Renaming a parameter consistently is permitted.
