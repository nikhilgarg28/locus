L0511: Specification and implementation disagree

A loaded spec requires a complete, unique implementation. Header and definition signatures must match, including their proof propositions. Repeated spec blocks add disjoint members; they do not override them. Additional exposed implementation members are rejected.

```rust reject L0511
spec mod counter { fn read() -> u8; }
impl mod counter { fn read() -> u16 { 0 } }
```

Repeat the required signature and supply a checked body. Diagnostics point to both the implementation and the required header when a matching member exists.
