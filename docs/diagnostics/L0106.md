L0106: Ambiguous single-field tuple

A one-field tuple needs a trailing comma. Parentheses without that comma group an expression or type; they do not introduce a tuple field. Write (value: u8,) when the field name is needed for a later dependent field.

Example from `tests/corpus/reject/one_field_tuple_type.lc`; the full file is a regression test.

```rust
// A one-field tuple type without its trailing comma.
fn first(n: u8) -> (out: u8) {
    (n,)
}
```

Language, as built: [1.3:2](../../atlas.html#/doc/language/spec-1.3:2).
