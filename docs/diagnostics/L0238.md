L0238: Arithmetic operator has unsupported operands

The operator is unavailable at the operand type or the operand machine widths disagree. Arithmetic is not defined on bool. Select a supported numerical type and make conversions explicit; logical arithmetic uses its own total operations.

Example from `tests/corpus/reject/operator_mixed_types.lc`; the full file is a regression test.

```rust
// An operator is between two values of one type, as a comparison is; the
// error names the cast that would make them one.
fn widen(a: u8, b: u32) -> u32 {
    a + b
}

#[terminates] #[no_panic] #[no_io]
fn exact(a: u8, b: Int) -> Prop {
    prop!(a * b == 6)
}

// On `bool` and other types there is no arithmetic at all.
fn on_bools(a: bool, b: bool) -> bool {
    a + b
}

fn negated_bool(a: bool) -> bool {
    -a
}
```
