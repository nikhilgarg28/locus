L0233: Field update would invalidate dependent evidence

A later field’s type depends on the field being changed. Updating only the data would leave its accompanying proof about the old value. Reconstruct and replace the whole aggregate with fresh evidence for the new data.

Example from `tests/corpus/reject/assign_field_with_evidence.lc`; the full file is a regression test.

```locus
// A field that evidence in the same struct depends on cannot be assigned
// alone: the rebuilt value would carry evidence about the old field. The
// whole value is replaced instead, as `set_whole` does.
struct Percent {
    value: u8,
    in_range: @(value <= 100),
}

fn set(p: Percent, v: u8, fits: @(v <= 100)) -> Percent {
    let mut copy = p;
    copy.value = v;
    copy
}

fn set_whole(p: Percent, v: u8, fits: @(v <= 100)) -> Percent {
    let mut copy = p;
    copy = Percent { value: v, in_range: fits };
    copy
}
```
