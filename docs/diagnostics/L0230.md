L0230: Unfilled proof obligation

The checker needs evidence of the stated claim and the available proof does not establish it. JSON includes the normalized claim, relevant facts, a counterexample when known, and a checked explicit form when one was found. A failed search alone does not prove the claim false. Add the missing premise, a lemma application, or an explicit conversion such as rewrite!, fold! or unfold!.

Example from `tests/corpus/reject/assign_join_snapshot.lc`; the full file is a regression test.

```locus
// Case 10 of the mutation design, the half that must fail: the arms assign
// `x` and prove the bound, but nothing carries the evidence out of the
// branch, so after the join nothing is known of `x`. Evidence bound with
// `let`, or stated with `prove!`, is a snapshot; `assign_join_evidence.lc`
// carries it out as the branch's value, and `tracked_refresh.lc` in
// `accept` carries it as tracked evidence, `let mut ok: @(x <= 2)`.
fn clamp(n: u8) -> u8 {
    let mut x = n;
    if x < 2 {
        x = 1;
        prove!(x <= 2);
    } else {
        x = 2;
        prove!(x <= 2);
    }
    prove!(x <= 2);
    x
}
```
