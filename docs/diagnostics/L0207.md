L0207: Value is not callable

The callee does not have a supported function, logical callable or proof-application type. A named-field struct uses brace construction rather than a function call. Check the resolved declaration, not just whether its name resembles a constructor.

Example from `tests/corpus/reject/call_of_a_struct.lc`; the full file is a regression test.

```rust
// A call of something that is not a function.
struct Lock {
    failures: u8,
}

fn first(n: u8) -> Lock {
    Lock(n)
}
```

Language, as built: [1.3:1](../../atlas.html#/doc/language/spec-1.3:1).
