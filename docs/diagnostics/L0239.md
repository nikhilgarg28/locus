L0239: Assertion is not proved under no_panic

An assertion may panic unless its condition is already established. In a no_panic function, the compiler requires evidence instead of inserting an unchecked promise. Prove the condition, strengthen the function’s input contract, or reconsider the no_panic guarantee.

Example from `tests/corpus/reject/assert_under_no_panic.lc`; the full file is a regression test.

```locus
// `assert!(c)` in a function that promises `no_panic` needs evidence of
// `c`, found as a hole is filled; nothing here speaks of `x`. The failing
// arm is the panic the promise forbids.
#[no_panic]
fn unchecked(x: u8) -> u8 {
    assert!(x <= 3);
    x
}

// A `debug_assert!` is checked in the debug build, so it needs the
// evidence too.
#[no_panic]
fn unchecked_in_debug(x: u8, small: @(x <= 3)) -> u8 {
    debug_assert!(x <= 2);
    x
}
```
