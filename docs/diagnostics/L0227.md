L0227: Proof elimination would expose erased information

An inhabited proof may be inspected only to construct further evidence. Selecting runtime data or extracting an arbitrary logical witness from a proof would give proof identity an observable meaning. Keep witness-dependent reasoning inside a proof-producing match.

Example from `tests/corpus/reject/evidence_chooses_a_value.lc`; the full file is a regression test.

```locus
// Evidence is erased, so it cannot choose a value.
fn pick(p: Prop, q: Prop, h: @(p || q)) -> u8 {
    match h {
        Or::Left(_) => 0,
        Or::Right(_) => 1,
    }
}
```
