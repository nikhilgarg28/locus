L0510: Unsupported specification form

The initial spec grammar supports concrete module/type interfaces containing public-by-default function and constant headers. Generic specs, explicit visibility on members, public representation fields and representation derives are not supported yet.

```rust reject L0510
spec mod counter { pub fn read() -> u8; }
```

Remove the member's `pub`; put the interface visibility on `spec mod counter` instead.

Language, as built: [1.29:1](../spec/18-specifications.md).
