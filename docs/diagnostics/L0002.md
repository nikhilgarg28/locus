L0002: Unterminated block comment

A block comment starts with /* and ends with */. Nested block comments need a closing delimiter for every opening delimiter. Add the missing closing delimiter before the next declaration.

Example from `tests/corpus/reject/unterminated_block_comment.lc`; the full file is a regression test.

```locus
// A block comment that is never closed.
fn first(n: u8) -> u8 { n }
/* the rest of the file
```
