L0209: Runtime call in a logical context

An ordinary fn may have runtime effects and cannot be executed while defining a constant or checked logical computation. A callable logical implementation needs an explicit logic fn declaration and must satisfy its purity, totality and result-type restrictions.

Example from `tests/corpus/reject/constant_calls.lc`; the full file is a regression test.

```rust
// A constant with a runtime form is computed by Rust itself, which does
// not call a function; a value a function computes is a function.
#[terminates] #[no_panic] #[no_io]
fn double(n: u8) -> u8 {
    n.wrapping_add(n)
}

const FOUR: u8 = double(2);

const PAIR: (u8, u8) = (1, double(1));

// A constant of a ghost type has no runtime form, and may.
logic fn logical_double(n: Int) -> Int { n + n }
const four: Prop = prop!(logical_double(2) == 4);
```
